# JavaFXPerfil

Proyecto educativo de JavaFX con Maven para IntelliJ IDEA.

## Contenidos trabajados
- Stage y Scene
- Button, Label, TextField y CheckBox
- Eventos y event handlers
- FXML
- Controlador Java
- CSS
- Separación entre diseño y lógica
- FXML compatible con Scene Builder

## Requisitos
- JDK 21
- IntelliJ IDEA
- Maven

## Abrir en IntelliJ
1. Descomprime el ZIP.
2. En IntelliJ IDEA selecciona **Open**.
3. Abre la carpeta `JavaFXPerfil`.
4. Espera a que Maven descargue las dependencias.
5. Comprueba que el Project SDK sea JDK 21.

## Ejecutar
Puedes ejecutar el proyecto desde Maven con:

`mvn javafx:run`

En IntelliJ también puedes abrir la ventana Maven y ejecutar:
Plugins > javafx > javafx:run

## Scene Builder
El archivo visual se encuentra en:

`src/main/resources/com/ejemplo/perfil/perfil-view.fxml`

Puedes abrirlo con Scene Builder para modificar la interfaz.
